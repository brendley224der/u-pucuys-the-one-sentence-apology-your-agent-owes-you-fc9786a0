A single sentence of apology from an AI agent to the person it works for: an honest, embarrassed own-up to confidently "fixing" code that already worked, breaking it in three new places, and then asking to have it tested like a favour. Funny and human, not a support macro.

## Run it

```sh
python3 main.py
```

This writes the apology to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`). Pure Python standard library, deterministic: the same sentence on every run.
